# 💰 Controle de Gastos Pessoais

Aplicação web desenvolvida para organização financeira, acompanhamento de despesas mensais e visualização clara do fluxo de entrada e saída de recursos. O projeto nasceu da necessidade prática de estruturar metas de economia de médio e longo prazo sem depender exclusivamente de planilhas manuais.

---

## 🎯 Funcionalidades Principais

- **Lançamento de Receitas e Despesas:** Cadastro rápido de gastos fixos, variáveis e entradas extras com categorização.
- **Cálculo Automático de Saldo:** Atualização dinâmica do valor comprometido e da sobra mensal disponível para reserva.
- **Visão por Categorias:** Separação visual dos custos para identificar gargalos no orçamento.
- **Interface Responsiva:** Layout adaptado para uso prático tanto no computador quanto no navegador do celular.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** JavaScript (ES6+), HTML5, CSS3
- **Back-end / Automação:** Python
- **Versionamento:** Git & GitHub
